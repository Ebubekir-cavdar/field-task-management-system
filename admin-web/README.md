# Saha Görev Yönetimi - Web Yönetici Paneli (React + Vite)

Bu proje, Saha Görev Yönetim Sistemi için geliştirilmiş responsive (PC, Tablet, Telefon) web yönetim panelidir.

## 🚀 Çalıştırma

Gereksinimler: Node.js (v18+)

```bash
# 1. Bağımlılıkları Yükle
npm install

# 2. Geliştirme Sunucusunu Başlat (Port 5173)
npm run dev
```

Tarayıcınızda açın: `http://localhost:5173`
